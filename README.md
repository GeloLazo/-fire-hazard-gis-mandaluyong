# Fire Hazard Mapping System of Mandaluyong City

A comprehensive GIS-based web platform engineered for real-time fire risk assessment, spatial hazard mapping, and incident tracking across Mandaluyong City, integrated with time-series forecasting models.

## System Overview

* **Platform Architecture:** Full-stack GIS Web Application (React, Node.js, Express, TypeScript, PostgreSQL)
* **Spatial & Mapping Core:** Interactive mapping layers displaying Mandaluyong City barangay boundaries, fire hydrant networks, and facility locations.
* **Predictive Analytics:** Time-series forecasting integration for proactive fire risk evaluation and incident mitigation.
* **Role-Based Access:** Dedicated administrative controls and public reporting interfaces.

## Key Features

* **Interactive GIS Mapping:** Real-time visualization of fire stations, hydrants, and hazard zones within Mandaluyong City.
* **Emergency Reporting & Status Tracking:** Live tracking of active emergencies and streamlined incident report submission.
* **Administrative Dashboards:** Secure portals for monitoring database records, risk levels, and spatial data analytics.
